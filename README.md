## Aktuelles Projekt · ALDI & LIDL Watcher

**Prepaid-Datenvolumen überwachen und Nachbuchungen kontrolliert vorbereiten.**

Der [Watcher](https://github.com/chhubeny90-cell/aldi-watcher) verbindet Python, Browsersteuerung, GitHub Actions und SQLite. Monitoring und Buchung sind getrennt; persistente Buchungszustände schützen vor unkontrollierten Wiederholungen.

| Bereich | Stand |
| --- | --- |
| Geplanter GitHub-Lauf | Ausschließlich lesendes Monitoring |
| Nachbuchung | Separater Buchungskern; noch nicht live freigegeben |
| Offene Live-Prüfung | Anmeldung, Tarifberechtigung, Konto-Selektoren und Buchungsbestätigung |

[Projekt ansehen →](https://github.com/chhubeny90-cell/aldi-watcher) · [Betrieb & Fehlerbehebung](https://github.com/chhubeny90-cell/aldi-watcher/blob/main/docs/monitoring-recovery.md) · [Issues](https://github.com/chhubeny90-cell/aldi-watcher/issues)
